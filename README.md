# מסיבת פיג׳מות אצל סבתא מרסל

לוח שיבוץ משפחתי ללילות אצל סבתא: https://asafkonyak.github.io/savta/

- האתר: `index.html` (GitHub Pages).
- המידע (שיבוצים, הערות, תגובות, צ׳אט) נשמר במסמך JSON ב־jsonblob.com. המזהה שלו ב־`data/blob.txt`.
- גיבוי יומי אוטומטי של כל המידע נשמר ב־`data/backup.json` (GitHub Action `data`). אם המסמך ב־jsonblob נמחק, ה־Action יוצר חדש מהגיבוי.
